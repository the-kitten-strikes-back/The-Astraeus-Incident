# 👽 The Astraeus Incident

> *Astraeus was never meant to reach its destination.*

A psychological sci-fi FPS where you awaken aboard a drifting deep-space vessel with fragmented systems, corrupted logs, and a mystery that defies comprehension. Navigate shifting corridors, uncover impossible truths, and confront an anomaly that distorts more than just space.

What began as a routine expedition has become something far worse.

---

## 🎮 Atmosphere & Story

Corridors shift. Signals repeat. Time fractures.

An impossible anomaly has formed near the ship—a gravitational singularity that doesn't just distort space, but memory, perception… and something deeper. Echoes of the crew linger in broken transmissions. As you navigate the collapsing interior of Astraeus, you must piece together what happened, uncover the truth behind the anomaly, and decide whether escape is even possible.

**Or if you were ever meant to leave at all.**

---

## 🎯 Key Features

- **Atmospheric FPS gameplay** - Exploration-focused first-person perspective
- **Narrative mystery** - Piece together fragmented logs and corrupted data
- **Environmental storytelling** - Uncover the fate of the crew through surroundings
- **Physics anomalies** - Reality-bending environmental puzzles
- **Psychological horror** - Tension, isolation, and the unknown
- **Multiple endings** - Your choices shape the outcome

## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- Pygame
- NumPy

### Installation

```bash
git clone https://github.com/the-kitten-strikes-back/The-Astraeus-Incident.git
cd The-Astraeus-Incident

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install pygame numpy

# Run the game
cd fps_game
python main.py
```
